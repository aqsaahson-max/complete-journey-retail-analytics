# Team contributions

This was an academic group project. The portfolio owner served as the group leader. The implementation and dashboard shown here represent the team's overall work.

Individual technical ownership has not been assigned in this public package because a verified member-by-member contribution breakdown was not supplied. Leadership should not be interpreted as sole authorship of every component. Team members may add their names and agreed contributions here before publication. Student identifiers and personal contact details are intentionally omitted.
